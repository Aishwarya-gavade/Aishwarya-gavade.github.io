# Aishwarya Gavade — Portfolio

Static HTML/CSS/JavaScript portfolio.

## Before deployment
1. Put your resume at `assets/Aishwarya_Gavade_Sr_Quality_Analyst_Lead.pdf`.
2. Put certificate files in `assets/certificates/` using the filenames referenced by `index.html`.
3. Replace the GitHub placeholder URL in `index.html` with your real GitHub profile.
4. Replace the Open Graph URL/image if you add a custom domain/social preview.
5. Deploy the folder to GitHub Pages, Netlify or Vercel.

## Structure
- `index.html` — portfolio page
- `assets/css/style.css` — responsive styles
- `assets/js/main.js` — navigation and dynamic year
- `assets/images/` — favicon and future images
